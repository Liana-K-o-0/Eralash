# Eralash

Eralash — сортировщик входящих писем

Программа, которая разбирает папку с письмами, определяет категорию
каждого письма по ключевым словам и раскладывает файлы по папкам. В конце
формирует статистику и журнал обработки.

Описание работы программы

Обработка имеет следующий вид:

inbox/ → чтение письма → классификация по правилам → перемещение в outbox/<категория>/ → лог + статистика + график (отдельно можно вызвать в терминале)

1.Чтение. Программа проходит по всем файлам в папке inbox/ и пытается преобразовать каждое письмо в объект (выделить тему, отправителя, текст).
2.Классификация. По ключевым словам в теме/тексте и по адресу отправителя определяется категория письма. Если ни одно правило не сработало письмо отправляется в категорию "неотсортированное".
3.Перемещение. Файл переносится в outbox/<категория>/.
4.Отчёт. Считается, сколько писем попало в каждую категорию, пишутся statistics.json и process_log.json, pie.png (по желанию).

Структура проекта

main.py         — точка входа: разбор аргументов, запуск, запись отчётов
processor.py    — чтение писем из inbox/ и перемещение в outbox/ (+ класс Email)
classifier.py   — правила и логика определения категории
logger.py       — сбор статистики, журнал, диаграмма
run.sh          — bash-скрипт запуска (Windows / Linux / macOS)

Требования

- Python 3.7 или новее
- Библиотека matplotlib (используется в `logger.py`)

Установка библиотеки через терминал:

bash
pip install matplotlib

Установка

bash
git clone https://github.com/<пользователь>/<репозиторий>.git
cd <репозиторий>
pip install matplotlib

Рядом с main.py должна лежать папка inbox/ с письмами. Папка outbox/
и подпапки категорий создаются автоматически при запуске.

Варианты запуск

1)Через bash-скрипт

На Windows скрипт запускается в Git Bash (правый клик в папке проекта → «Open Git Bash here»):

bash
bash run.sh

Скрипт сам выбирает команду Python под систему ("py" на Windows, "python" на Linux/macOS) и проверяет, что папка inbox/ существует.

2)Напрямую через Python

На Windows:

bash
py main.py inbox --show-logs (без графика)

py main.py inbox --show-logs --pie (с сохранённым графиком)

На Linux / macOS:

bash
python3 main.py inbox --show-logs (без графика)

python3 main.py inbox --show-logs --pie (с сохранённым графиком)

Аргументы командной строки

| Аргумент        | Описание                                                        |
|-----------------|-----------------------------------------------------------------|
| <путь>          | Папка со входящими письмами (по умолчанию `inbox`)              |
| --show-logs     | Вывести итоговую статистику и журнал в консоль                  |
| --config <файл> | Подключить дополнительные правила классификации из JSON-файла   |
| --pie           | Построить круговую диаграмму сортировки писем                   |

Примеры:

bash
py main.py inbox --show-logs
py main.py ./inbox --config my_rules.json --show-logs
py main.py inbox --pie

Категории

Письмо попадает в одну из категорий (создаётся как папка внутри `outbox/`):

- "спам, фишинг, вредоносные"
- "технические сбои и проблемы ПО"
- "доступы, права, учетные записи"
- "документы, бухгалтерия, юридические запросы"
- "прочие запросы и уведомления"
- "неотсортированное" - если ни одно правило не подошло
- "нечитаемый формат" - если файл не удалось прочитать или его тип не поддерживается

Поддерживаемые форматы писем

- .txt, .eml — текст с заголовками (Тема`/`Subject, От кого/From, Кому/To)
- .json — поля subject, from, body
- файлы без расширения — читаются как текст
- остальные типы (например .jpeg) — помечаются как нечитаемые

Настройка правил через "--config"

Можно добавить свою категорию через JSON-файл.
Файл должен быть содержать категорию, приоритет категории, ключевые слова для темы и текста письма, ключевые слова для имени отправителя.
Образец:

json
{
  "rules": [
    {
      "category": "название категории",
      "priority": 15,
      "keywords": ["ключевое слово", "ещё одно"],
      "from_contains": ["@example.com"]
    }
  ]
}

"priority" задаёт порядок проверки - чем меньше число, тем раньше срабатывает
правило (приоритеты существующих категорий: спам - 5, технические сбои - 10, доступы - 20, документы - 30, прочее - 40 (названия категорий сокращены для удобства)). "keywords" ищутся в теме и тексте письма, "from_contains" - в адресе отправителя.

Результат работы

После запуска появляются:

- outbox/<категория>/ — письма, разложенные по папкам
- statistics.json — сколько писем в каждой категории
- process_log.json — журнал: какое письмо в какую категорию попало
- pie.png — круговая диаграмма сортировки писем
